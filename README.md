# FellahAlert 🌾

AI-powered agricultural advisory system for Moroccan smallholder farmers, delivered entirely over **WhatsApp** in **French** and **Darija (Moroccan Arabic)**.

---

## What it does

Farmers send a WhatsApp message describing their situation (crop, city, problem) and receive:

1. **Personalised advice** — Generated by Gemini 2.5 Flash, grounded in local agronomy knowledge via BM25 RAG
2. **Weather context** — Real-time data from the NASA POWER API (temperature, humidity, rainfall)
3. **Crop disease diagnosis** — Farmers can send a **photo** of their crop and receive a diagnosis with treatment recommendations (Gemini Vision)
4. **Seasonal calendar** — Sowing and harvest dates for Moroccan crops by city

---

## Architecture

```
WhatsApp (Meta Cloud API)
        │
        ▼
   FastAPI (Python)
   ├── Parser        ← Gemini extracts crop / city / problem from free-text (FR + Darija)
   ├── RAG           ← BM25 TF-IDF over 15 agronomy knowledge chunks
   ├── AI Advice     ← Gemini 2.5 Flash generates contextual advisory
   ├── Vision        ← Gemini Vision diagnoses plant disease from photos
   └── NASA POWER    ← Live weather data for any Moroccan city
        │
        ▼
   PostgreSQL        ← Interaction logs, analytics, blocklist
        │
        ▼
   Dashboard         ← Admin analytics (messages, crops, cities, status)
```

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python 3.11, FastAPI, Uvicorn |
| AI | Google Gemini 2.5 Flash (text + vision) |
| RAG | In-memory BM25 TF-IDF (no vector DB needed) |
| Weather | NASA POWER API |
| Messaging | WhatsApp Business Cloud API (Meta) |
| Database | PostgreSQL (via asyncpg) |
| Deployment | Render.com (Docker) |

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/ask` | Submit a farmer query, receive AI advice |
| `POST` | `/diagnose` | Submit a crop photo URL for disease diagnosis |
| `GET` | `/calendar?city=Agadir` | Seasonal crop calendar for a city |
| `GET` | `/stats` | Public usage statistics |
| `GET` | `/analytics` | Full analytics (requires ADMIN_TOKEN) |
| `GET/POST` | `/whatsapp` | WhatsApp webhook (Meta verification + messages) |
| `GET` | `/whatsapp/status` | WhatsApp integration health |
| `GET` | `/status` | AI + NASA connectivity check |
| `GET` | `/health` | Full health check (DB + Gemini + NASA) — used by Render |
| `GET` | `/ping` | Ultra-fast keep-alive (no external calls) — used by UptimeRobot |

## Running Locally

```bash
# 1. Clone
git clone https://github.com/aicha03-JavaDev/-fellahalert.git
cd -fellahalert

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set environment variables
export DATABASE_URL="postgresql://user:pass@localhost:5432/fellahalert"
export GEMINI_API_KEY="your_google_ai_studio_key"
export WHATSAPP_PHONE_ID="your_phone_number_id"
export WHATSAPP_ACCESS_TOKEN="your_access_token"
export WHATSAPP_VERIFY_TOKEN="your_chosen_token"
export ADMIN_TOKEN="your_admin_secret"
export SESSION_SECRET="your_session_secret"

# 4. Run
python main.py
```

The server starts on port `8000` by default (or `$PORT` if set).

## Deploying to Render

A `render.yaml` is included for one-click deploy on Render's free tier.

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → **New → Web Service**
3. Connect this repository — Render will auto-detect `render.yaml`
4. Add the environment variables listed above
5. Deploy — Render checks `/health` before routing traffic

> **Keep-alive tip:** Render's free tier sleeps after 15 minutes of inactivity. Add `https://your-app.onrender.com/ping` to [UptimeRobot](https://uptimerobot.com) (free) to keep it awake.

## WhatsApp Setup

1. Create a Meta Developer app at [developers.facebook.com](https://developers.facebook.com)
2. Enable **WhatsApp Business Cloud API**
3. Set your webhook URL to `https://your-app.onrender.com/whatsapp`
4. Set your verify token to match `WHATSAPP_VERIFY_TOKEN`
5. Subscribe to the **messages** webhook field

> 🌡️ Température actuelle à Casablanca : 22°C, humidité 68%...
